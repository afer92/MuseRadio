Votre navigateur n'est pas compatible. Utilisez Google Chrome ou Microsoft Edge sur ordinateur. L'installation nécessite une connexion sécurisée (HTTPS).

Démarrage rapide après installation

  1. Branchez la carte en USB-C sur ordinateur (Chrome ou Edge) et cliquez sur Installer le firmware.
  2. Connectez-vous au point d'accès Wi-Fi Raspiaudio-radio-full (mot de passe : 12345678) pour renseigner votre réseau.
  3. Dans Home Assistant, activez « Autoriser l'appareil à exécuter des actions Home Assistant » dans les options de l'appareil ESPHome.
